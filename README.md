# Hotel Management System 🏨

Full-stack hotel management web app built with Laravel.

## Features
- Date-based room availability & booking
- Add-on services per room (custom packages)
- Admin dashboard — room & category management
- Booking records & monthly reports
- Automated email notifications to customers
- Database-driven chatbot for hotel info & room availability

## Tech Stack
Laravel, PHP, MySQL, JavaScript, HTML, CSS
